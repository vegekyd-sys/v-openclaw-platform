# Original H5 Candidate validation

`native-smoke.mjs` runs the unchanged H5 through task-owned Chrome, WebRTC and
the real backend. Original buttons receive trusted CDP mouse presses/releases;
Chrome uses its default autoplay policy. A private PulseAudio source feeds synthetic user WAV clips to
the browser's original processed `getUserMedia` track. Its separate output sink
prevents accidental digital speaker-to-microphone feedback. No assistant,
data-channel or backend result is generated by the observer.

The private plan must set `GPT_LIVE_H5_MEMORY_QUERY` to the intended real retrieval target; the framework contains no person's test query.

The two cases cover a single long memory → official Web → same-agent child
task, and pending-task interruption → cancellation → close/reconnect. The
long-task receipt separately checks the requested ordering, child execution
identity, exact tool results, a short speakable fact before final, all final
chunks, values, timezone, actual player state and decoded native PCM.

Real `session.tool` envelopes preserve both `payload.ts` (source time) and
observer receipt time. Exact terminal child session IDs can additionally be
read from the owned SQLite snapshot in `mode=ro`, using the native active
transcript selection. Empty Gateway child history is not evidence of absent
tools. Terminal reply text is never substituted for an actual tool result.

`turn.done` supplies transcript metadata, not playback completion. Before an
ordinary end-call the observer requires 750ms of continuous attached, live,
unmuted, unpaused player quiet and retains the RTP samples. A close already
performed through the original H5 is accepted only with its exact voice owner,
successful close request, closed peer connection and ended capture tracks.

Receipts retain independent failures. The provider-default path has no local
HTML mute action, so the required 100ms client attenuation gate remains a
separate failure unless actually implemented and observed. Native interruption
and correct new-topic audio have their own identity and drain gates. Silence
after cancellation cannot prove a late callback was rejected; that requires a
real callback/drop witness for the cancelled owner. Memory and official page
truth require independent review of the saved source content.

All evidence is private (0600); no credentials belong in a committed report.
Synthetic user PCM and digital playback checks do not establish physical echo
cancellation or human listening acceptance. `GPT_LIVE_H5_EXPERIENCE_AFTER_TESTS=1`
keeps the same owned Candidate idle for a bounded review window after every
case has saved its result, including failures. The readiness record labels
failed cases as diagnostic and never marks product or human acceptance.
