# 三模型统一 JEV 决策层：Candidate 实验

用户授权：GPT Live、豆包·小何、Grok 使用同一个决策层，接入前冻结基线，再比较真实任务路径。当前补丁仅 Candidate；不合 dev，不部署共享 VLab 或生产 V。

## 行为

语音适配器保留各自原生协议、持续输入、播放及打断路径。工具选择统一交给固定版本 `typesafe/jev-1.13`，实际响应返回的模型身份单独记录。普通聊天仍由语音模型完成；操作与查询经过统一决策器。

- Memory、Web、网页原文、本人飞书日程、当前时间：直接执行现有 OpenClaw 工具，保留真实结果与权限边界。
- 自然结束通话、取消当前任务、询问进度：决策后执行当前 owner 的控制动作，不启动新的 Agent。
- 调研、比较、规划、报告、未包装的工具或参数：交给原个人 OpenClaw Agent，不削减其工具能力。
- 音量控制暂未接入真实播放器，因此不会向 JEV 宣称可执行。

小何/Grok 向前端只公开 `route_task`；GPT Live 通过其已有 native client delegation 接入同一决策器，不向不支持函数工具的 native wire 发送伪造 function call。宿主以完整、实际 USER 为输入，不以模型补写的参数授予权限。请求重放去重、过期 owner、取消信号与新的 USER 都有检查。

GPT Live 的决策不排在长任务后面。决策和短工具可独立处理，Agent 任务单独串行并限制队列。JEV 结束回执有自己的 decisionId/model，不伪装成后端 Agent run。原 H5 必须收到真实 owner 接受、实际告别与播放静尾，才关闭电话。

不确定的结束意图澄清；JEV 超时不能默默转成 Agent。API key 只保存在服务端私有环境。默认关闭此实验，原三个模型路径保持。

## 基线与测量

历史上线版本为 `v2026.9.1-db91.6-voice-reliability-20261008`；本轮真实基线使用已有的可复用 Candidate（旧 Gateway 2466d675 runtime + dd5e4cdb H5）。两者不能当成同一个整包。运行时与 H5 文件实际 hash 已独立冻结，旧 ready 元数据不能替代 HTTP 或 runtime 文件核对。

使用同一份 USER WAV：Memory 查询和自然告别。真实 getUserMedia 输入、原 H5、原 provider、真实 Gateway 工具和扬声器 PCM；不合成 assistant、工具结果或 data-channel 回执。分别记录 USER 播完到工具开始、工具返回、实际电话关闭；扬声器 PCM 保留供独立分析，尚未提取可靠的首个回答可听时间。

完整交替多轮 A/B 尚未完成。本人共享 session 会随真实通话增加历史，因此现有样本是探索测量，不能声称已经做成固定上下文的严格 A/B。正式比较要固定同一上下文，并分开冷/暖工具、决策网络耗时与音频播放耗时。
