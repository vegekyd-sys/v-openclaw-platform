# 三模型统一 JEV 决策层：Candidate 实验

用户授权：GPT Live、豆包·小何、Grok 使用同一个决策层，接入前冻结基线，再比较真实任务路径。当前补丁仅 Candidate；不合 dev，不部署共享 VLab 或生产 V。

## 行为

语音适配器保留各自原生协议、持续输入、播放及打断路径。工具选择统一交给固定版本 `typesafe/jev-1.13`，实际响应返回的模型身份单独记录。普通聊天仍由语音模型完成；操作与查询经过统一决策器。

- Memory、Web、网页原文、本人飞书日程、当前时间：直接执行现有 OpenClaw 工具，保留真实结果与权限边界。
- 自然结束通话、取消当前任务、询问进度：决策后执行当前 owner 的控制动作，不启动新的 Agent。
- 调研、比较、规划、报告、未包装的工具或参数：交给原个人 OpenClaw Agent，不削减其工具能力。
- 音量控制暂未接入真实播放器，因此不会向 JEV 宣称可执行。

小何/Grok 向前端只公开 `route_task`；GPT Live 通过其已有 native client delegation 接入同一决策器，不向不支持函数工具的 native wire 发送伪造 function call。宿主以完整、实际 USER 为输入，不以模型补写的参数授予权限。请求重放去重、过期 owner、取消信号与新的 USER 都有检查。

GPT Live 的决策不排在长任务后面。决策和短工具可独立处理，Agent 任务单独串行并限制队列。JEV 结束回执有自己的 decisionId/model，不伪装成后端 Agent run。原 H5 必须收到真实 owner 接受、实际告别与播放静尾，才关闭电话。

不确定的结束意图澄清；JEV 超时不能默默转成 Agent。API key 只保存在服务端私有环境。默认关闭此实验，原三个模型路径保持。

查询参数由 JEV 从实际 USER 的原文片段中选择；宿主只生成去掉查询操作措辞的候选，不改写事实对象或真实排除条件。固定日期范围由代码计算；未包装的日期、联系人、写入或复杂参数继续交给 Agent。JEV 是动作判断器，不能当成任意工具参数生成器。

共享的部分是动作目录、判断与权限校验；三个模型保留各自的语音传输适配。普通聊天由语音模型回答，任务或控制的具体选择经过 JEV。小何/Grok 调用唯一 `route_task`，GPT Live 使用实际 native delegation；没有向 GPT Live 伪造函数工具协议。

GPT Live r4 和 r5 的挂断 FAIL 保留：实际 JEV 已接受结束，原生模型也说出告别，但网页未收尾。原因有两处：宿主轮询回执晚于 native 告别时丢弃已有证据；native 工具结果实际追加在已经开始的同一轮 assistant 内，网页误等下一轮。网页现只在匹配的原生 context ACK 后采集实际 PCM，保留当前未终止的同一 native turn；真实 JEV 接受回执到达后仍要求新连续 750 ms 静尾。没有宿主接受、音频、终止、或新 USER 到来时不能自动关闭。Gateway 保持运行，仅更新自有空闲 H5 服务。新 r6 原 H5 完成真实 Memory 查询和自然挂断：工具开始 2240 ms、返回前端 4062 ms；观察器关闭耗时 6393 ms，原时间戳只读重算 6379 ms。实际决策模型为 `typesafe/jev-1.13-20260917`，Memory 判断 794 ms、结束判断 464 ms。原 native ACK、真实告别“稍等，我这就处理。拜拜！”、ACK 后未静音 PCM、terminal 和 750 ms 连续静尾已从原文件复核；最大采样间隔约 72 ms。此为原网页 PCM 采样证明，不替代独立 RTP/物理 Safari 验收；原宿主轮询接受回执没有另行归档。r6 问候实际完成；旧缺问候、旧挂断 FAIL 不改。
