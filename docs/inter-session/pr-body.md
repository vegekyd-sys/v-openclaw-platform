# 跨 session 原生渠道协同候选

跨会话派活原来可能只在后台运行，目标聊天缺少原生回复过程，发起方还可能等待或提前拿到“已开工”。本候选把 `sessions_send` 接到渠道入站桥：目标聊天显示请求和原生回复卡，Gateway 持久化排队、后台工作、子任务与批次，收齐后在发起会话唤醒一次并汇报。

包含协同插件、核心准入及四渠道桥、配置/发版/回滚工具与候选驱动。Worker/VDS 补正并发 RPC 被 queued 占位遮住、后台工作脱离任务系统、失败回程说明诱发重新派活的问题。工作区技能仍是待发布草稿，见 `docs/inter-session/workspace-changes.md`。
