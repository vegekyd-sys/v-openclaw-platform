| Memory 与 Web | 使用私有可写快照及真实 provider；保留确切工具名、参数、结果、来源和最终原 H5 语音。健康检查、空库、模拟结果不能替代。 |
| 父子续传 | 真实 spawn/yield、子任务工具结果、父任务自动恢复、最终结果回到原通话。 |
| 提前事实与最终值 | 阶段内容有公开事实及真实工具结果依据，原生 append、字幕、未静音 PCM 对齐；最终数字/日期/随机值来自指定最终结果。原有失败保留。 |
| 等待与短附和 | 等待阶段不重复口头承诺，播报有新增信息；短附和不会误锁播放或无故取消后台任务。 |

| 结束与重连 | 所有本通话 RTC、麦克风、声音、SSE/timer 关闭；重拨使用新通话，不播放旧回答或残留铃声。 |
| 回声与 UI | AEC 设置与持续输入真实记录；自动合成输入仅验证数字链路，物理扬声器回录留给真人声学验收。字幕轮次、拨号、接通、恢复声音、错误和结束状态一致。 |

## 执行顺序和证据

1. 修复已定位的播放锁及明确的播放失败恢复；用有意义的确定性回归验证状态路径。
2. 候选工具环境先确认私有路径、Memory 数据来源、Web provider 和实际工具可用性，避免加载第二个外部消息消费者。
3. 用同一持续麦克风处理 track 驱动原 H5，真实语音长任务完成 Memory → Web → 多步/子任务 → 最终结果，并保留音频、公开进度和工具证据。
4. 在同一候选版本下覆盖安静/短附和/改题、取消、关闭与重拨；只对新改动或真实失败重测。
5. 固定最终源码和输入 hash，完成桌面与手机界面检查；启动带明确时限与清理责任的 Candidate 真人入口。

状态分别记录为：源码修复、确定性回归、真实候选工具/语音实测、真人听觉与声学验收。任何一层通过不提升其他层状态。

### 首轮真实长任务结果与发现

Candidate `candidate-c379e635-6f3d-4fc0-92f8-b504e614ddc6` 的真实 Memory Search 和 Web Search 均返回非空结果，原 H5 创建了 `gpt-live-1-codex` 的真实 WebRTC 通话。一次完整语音输入后，后台完成搜索、实际子任务、父任务自动恢复和后续等待/日期命令；用户没有催促“然后呢”。原 H5 收到了五个同一委派的最终块及完整最终字幕，实际解码 PCM 与未静音播放器对齐，结束前有连续 1000 ms 的真实安静尾段。

这轮整体仍为 **FAIL**：用户要求的等待和日期命令被父任务执行，未留在指定同一个子任务中；搜索合成答案也未充分核对官方原文和传输方式。提前校验数已真实播出，但其播出先于对应的可播报通道证据，不能把上下文朗读算作可播报事实链路通过。插话、取消、重连没有在期限内开始，不能借用旧版结果。原始失败回执、单独观察到的自动续做和数值保真均保留，不回写成整轮通过。

已补充完整执行者/步骤链路约束，以及实际读取官方页面后才给出官方接口结论的来源要求。下一轮真实复测还需证明这些要求确实执行，并完成未覆盖的控制路径；提示词与本地检查通过不能代替实测。

原生 `commentary` 通道与“不要朗读”指令不足以保证静默。新的控制器不把等待话或长文章送到原生模型，只保留后台上下文和诊断指纹；选出的短事实通过 `speakable` 通道发出，最多每 15 秒一次，并在取消、关闭或最终结果时清理待发事实。实际出现过的 Markdown/代码碎片和下一步计划不能替换待播事实。最终结果仍完整保留。这是本轮修复，仍需新的真实通话证明。

## Candidate 启动隔离问题

完整工具环境的原生数据库检查已通过。后续启动暴露了真实配置里额外的插件路径、SDK 链接及 npm 缓存继承；失败发生在工具调用和模型通话前。修复仅在私有 Candidate 进行，并保留各轮原始失败回执。

后台模型名称与执行 runtime 需分别核对：当前选用的 `deepseek-v4-pro/flash` 使用 `vlab-worker`，但部分未选模型映射显式要求 Codex 或 Claude CLI。原生启动会扫描全部模型映射，因此 Candidate 需将所保留的执行插件和安装依赖私有化；不能靠强制切换所选模型的 runtime 绕过检查。共享 PID、登记的 runtime/config 指纹稳定只证明该范围，不能据此断言全部共享缓存和状态无写入。

本轮 Candidate 的执行范围为 Makaron 主任务和同 agent 的真实子任务；保留其实际主模型、备用模型与子任务模型，并开放 Memory、Web、执行和子任务工具。其他 agent 不在这轮候选中启用。主配置和 Worker 配置的模型选择需分别记录，不能将 Worker 里的有效 Codex 引用当作未选别名删除。
