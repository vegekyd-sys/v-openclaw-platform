- 全局状态库：原生完整性检查在 state-lifecycle 锁内耗时 6682 ms，另一 Worker 获取锁在 5051 ms 超时。候选在原锁前顺序只读预热该文件，不生成校验证书、不跳过原生完整性检查。

- 受控取消时的独立故障：Worker 关闭 IPC 后，迟到的应答发送可触发未处理的 channel-closed 错误。候选只处理应答/ack 的关闭竞争，不改变请求、取消、准入或调度。
