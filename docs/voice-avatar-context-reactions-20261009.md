# Voice contextual avatar reactions — Candidate

The 36 approved performance images plus the idle portrait have reviewed actions, emotions, appropriate and inappropriate contexts. Performance images also carry dialogue relationship (listen, empathize, clarify, explain, encourage, apologize…), affect, energy, gaze, gesture and compatible-variation family labels. The old task scene is only a secondary cue. IDs and image paths are fixed; the display model cannot invoke tools.

All three voice providers share the same asynchronous display path. It sees at most six recent spoken user/V rows of 600 characters, actual task state and current speaker. The displayed image and semantic anchor are used locally for compatibility, but are not fed back as evidence for the model to keep its own prior choice. Full backend documents and tool arguments/results are excluded. Context stays in memory and goes to the existing server-side avatar Decision provider, without transcript logging in the avatar audit.

## Conversation reaction and timing

A new user caption turn marks attention but preserves the last meaningful reaction while the selection is pending. Only the initial fallback uses neutral listening. Streaming captions are coalesced until 400 ms of stability, with a 900 ms maximum debounce; requests no longer wait five seconds. Revised or new user speech, closed owners and aborted requests invalidate old reactions. V's streaming response to the same unchanged user meaning no longer discards a valid reaction. History/current caption groups are restored to native creation order before selecting context. Selection never blocks the voice or Agent path. Hidden pages stop requests and variation; quiet waiting does not poll the provider.

Decision selects one of the 36 reviewed pictures. The old separate HOLD option has been removed: it treated a neutral fallback as an established semantic reaction and dominated new contexts. Choosing the same actual picture preserves the reaction without resetting its visible deadline. A meaningful changed reaction displays as soon as its asset is decoded. Task transitions cannot erase an existing response to the person speaking.

While a call is visible, an unchanged reaction varies within a reviewed compatible family. Energy and phase determine a roughly 2.75–4.4 second dwell, with a five-second maximum target. A compatible neighbor and a tiny neutral safety pair are preloaded; a stalled neighbor falls back to a decoded attentive image at the deadline. Initial offline/failed asset loading and suspended browser timers cannot provide a hard physical wall-clock guarantee. Existing 256/512 WebP assets are reused; the gallery is not preloaded. Reduced motion skips crossfades. Semantic meaning stays stable while the pose changes.

## Confidence and validation

The exact-picture confidence gate remains 0.5. A distribution split between hand-reviewed equivalent reaction images may instead qualify at 0.75 family probability mass (with valid normalized probabilities and at least 0.15 selected-picture confidence). A clear relative winner also qualifies with at least 0.3 confidence and a 0.12 lead over the runner-up in a valid normalized distribution, consistent with the selected score. This distinguishes ambiguity among 36 overlapping cosmetic poses from a conflicting tie; unrelated emotions cannot be combined into a family pass. This is solely a display decision, with no change to task/action authorization thresholds. Otherwise the current attentive/task fallback remains.

277 targeted H5 and direct-provider regression tests passed with zero skips. They include current-owner and revision checks on all three reservation paths, independent heartbeat while display is pending, stale/partial phrase rejection, bounded context and document exclusion, streaming response survival and creation-order regression, immediate semantic replacement, duplicate choices not extending a frame, compatible variation, hidden-page handling, and existing audio/microphone/control behavior.

The previous nine actual OpenAI Decisions samples (eight contexts and HOLD) used the existing Candidate provider, without starting voice. Seven contexts produced reviewed matching pictures, HOLD preserved the reaction, and one mixed surprise/explanation context remained uncertain and was withheld. The actual Decision-only durations were 450–1309 ms; these are not end-to-end voice latency or general emotion-accuracy acceptance. The first probe's exact-picture ambiguity was retained, then inspected: sadness split mass between two equivalent listening pictures; planning split between two planning gestures. Both qualify through the reviewed family check. The ambiguous surprise sample still does not qualify.

Prior Candidate evidence remains separate: the first contextual implementation had 268 local tests and eight provider probes, and an obsolete adapter import caused one failed H5 load before recovery. Those receipts are not overwritten.

This follow-up is Candidate only and reuses the trial URLs. It does not change speech transport, providers, task routing, OpenClaw Agent, Gateway runtime/config or final-answer interruption policy. Native final interruption remains partially verified and physical iOS/Safari acceptance remains incomplete. No dev/shared VLab/V rollout is included.

## Actual trial follow-up: neutral loop

The user reported only three looping expressions in a real sadness/comfort call. That conversation was read from the current trial page; no browser errors were present. There were no per-call selector logs, so the exact old call's requests could not be reconstructed. A fresh provider probe with the actual neutral anchor reproduced the selection lock: the HOLD choice dominated some contexts and other contexts were filtered for low individual confidence. Old UI-only, instantaneous precomputed-response replay did not expose this failure.

The fix removes HOLD as a competing model answer, avoids current-image anchoring, retains reactions across incoming captions, and prevents V's caption stream from cancelling a response to unchanged user meaning. Non-sensitive page counters show requests, applied selections and failure/supersession status; no dialogue is written to those diagnostics. A fresh eight-context actual provider probe returned gallery pictures for sadness, joy, curiosity, explanation, reading, planning and comfort, with the mixed surprise/explanation context choosing explanation. Decision-only times were 443–577 ms in that run; this is not a general latency benchmark or human acceptance. The previous failure evidence remains preserved.
